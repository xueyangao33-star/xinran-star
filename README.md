# 卡皮巴拉温泉小镇

手机和平板优先的自主识字游戏：[打开游戏](https://xueyangao33-star.github.io/xinran-star/)。

每关 5 个字，依次完成认识汉字、听音找字、看字选拼音、汉字拼音连连看。最后一轮的 5 对全部配好后才领取奖励；同音字允许匹配任一相同拼音。无需录音或家长确认，答错可重试，提示与首次选对分开记录。关卡完成不等于已能独立朗读。

50 个认读项目按提供的课本第 108 页前三课顺序（45 个生字＋5 个多音字）。audio 目录包含系统合成的中文语音；请连同 index.html 一起部署。

运行：`python3 -m http.server 8000`，访问 http://localhost:8000 。无需构建或安装依赖。

进度保存在当前浏览器，不跨设备同步。保留旧版家长确认数据和奖励，新版自主答题另行记录。可在家长记录页导出 JSON 备份。
