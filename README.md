# 卡皮巴拉温泉小镇

适合亲子陪读的汉字闯关游戏。按教材识字表前三课顺序，包含 50 个认读项目（45 个生字和 5 个多音字），分为 10 关。

## 运行

直接用浏览器打开 `index.html`，或运行：

```sh
python3 -m http.server 8000
```

访问 http://localhost:8000 。无需安装依赖或构建。

## 玩法

孩子看字认读，家长确认；点击提示显示拼音和词语。不录音、不计时、不扣分。完成关卡获得小镇装饰，支持复习、家长记录和 JSON 导出。

进度仅保存在当前浏览器的 localStorage 中，不跨设备同步。独立认读和使用提示分开记录，完成关卡不等于已经熟练掌握。

## 字表

以提供的二年级上册课本第 108 页识字表为依据，从“蝌”到“得”。蓝色多音字“教、没、种、为、得”使用该页标注读音。
